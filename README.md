# Urlbox plugin for Cursor

Full-page screenshots, PDFs and Markdown of any site, including bot-protected ones, from Cursor, through the hosted Urlbox MCP server.

Built for teams that capture third-party websites: brand protection, compliance evidence, media monitoring, and price or competitor intelligence. What you try in Cursor is the same capture you run in production through the Urlbox API, with delivery by webhook or to your own S3 bucket.

## Install
1. Cursor Settings > Plugins, search for Urlbox, Install. Or run `/add-plugin urlbox`.
2. Sign in with your Urlbox account when prompted. You need a Urlbox account, and renders count against your plan. Leave any OAuth client ID and secret blank.

## What it adds
- The `urlbox` MCP server at https://api.urlbox.com/mcp: screenshot, pdf, markdown, extract_text, scrape_html, record_video, render and describe_options, plus project, webhook, render history and usage tools
- A skill that tells the agent when to use them
